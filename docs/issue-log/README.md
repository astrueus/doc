# 问题收集

## 编号

- 文件名：`{三位序号}-{英文短名}.md`，例如 `001-mcp-write-parity.md`
- 序号从 `001` 起，**只增不改号**；下一篇用当前最大号 + 1
- 不要插入小数号、不要复用已占用序号
- 本表按序号升序；状态在表里改，不改文件名
