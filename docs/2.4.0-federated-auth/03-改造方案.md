# 03 · 改造方案

## 定位

```text
凭证登录（不动）          联邦登录（本期）
local / LDAP / http  →  Member  ←  Binder(Identity)
                            │
                            ▼
                   SetMember(member_id)   Web Session
                   （MCP Token 仍事后签发）
```

包名 `internal/auth/federated`，不要用 `oauth` 当整层名字（OAuth 是授权；本层是认人）。钉钉/企微只是协议适配器。

不引入 JWT Session；不把 LDAP 塞进 Provider。不建 `internal/service/`。

## 目录

```text
internal/auth/federated/
  provider.go      # Provider / Identity / Callback / StartResult
  registry.go      # 按 conf 注册已启用项
  state.go         # 生成/校验 state
  binder.go        # Identity → Member
  dingtalk.go      # 钉钉 Provider + 钉钉 HTTP 客户端（不保留 thirdparty 包）
  wework.go        # 企微
internal/model/MemberIdentity.go
internal/repository/member_identity_repo.go
internal/migrate/migrate_federated_identity.go
internal/controller/FederatedLoginController.go
```

`AccountController` 只保留账密/注册/找回；登录页 `Data["FederatedProviders"]` 来自 Registry。

## 接口

```go
type StartResult struct {
	Kind     string // "redirect" | "qr"
	URL      string
	QRParams map[string]string
}

type Callback struct {
	Query url.Values
	Form  url.Values
}

type Identity struct {
	Provider    string
	Subject     string
	UnionID     string
	Email       string
	DisplayName string
	AvatarURL   string
}

type Provider interface {
	Name() string
	Enabled() bool
	Start(ctx context.Context, state string) (StartResult, error)
	Complete(ctx context.Context, cb Callback) (*Identity, error)
}
```

- `Complete` 认人：钉钉/企微调对方 API 后丢弃 Access Token；以后 OIDC 校验 ID Token（本期不实现）。
- `Callback` 带 Query/Form，避免接口被 `code string` 锁死（SAML 可后补，见 06）。

## HTTP

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/login` | 登录页；已启用 provider 按钮/二维码 |
| GET | `/login/federated/{provider}` | 生成 state 入 Session；302 或 JSON（`Kind=qr`） |
| GET/POST | `/login/federated/{provider}/callback` | 校验 state；`Complete`；Binder；`SetMember` |
| 删除 | `/dingtalk_login`、`/qrlogin/:app` | 无兼容转发 |

JSON 仍为 `errcode` / `message` / `data`。

钉钉/企微后台 Redirect URI（均须 HTTPS 生产）：

```text
{baseurl}/login/federated/dingtalk/callback
{baseurl}/login/federated/wework/callback
```

## 绑定

1. `FindByProviderSubject(provider, subject)` 命中 → 更新显示名/头像（可选）→ 登录。
2. 未命中且 `auto_create_member=false` → 明确错误，不建号。
3. 未命中且允许建号 → 插入 `Member`（`auth_method=federated`）+ identity 行，同一事务。
4. **禁止**按邮箱自动绑定已有 `local`/`ldap` 账号（防抢绑）。换绑见 06。

账号：`fed` + 12 位 `[a-z0-9]`（provider+subject 的 sha256 截断），满足 `RegexpAccount`。  
邮箱：IdP 有合法邮箱则用；否则 `{account}@users.noreply.local`（仅占位，不发信）。  
密码：写入随机哈希，联邦账号走 `Member.Login` 时按 `auth_method=federated` 拒绝账密（除非日后设密，本期不做）。

## 配置

```ini
[auth]
federated_enable = true
auto_create_member = true
default_role = 2

[oauth]
# 仅 HTTP 账密转发，与联邦无关
http_login_url =
http_login_secret = "${DOC_HTTP_LOGIN_SECRET}"

[oauth.dingtalk]
enable = false
corp_id = "${DOC_DINGTALK_CORPID}"
app_key = "${DOC_DINGTALK_APPKEY}"
app_secret = "${DOC_DINGTALK_APPSECRET}"
qr_key = "${DOC_DINGTALK_QRKEY}"
qr_secret = "${DOC_DINGTALK_QRSECRET}"

[oauth.wework]
enable = false
corp_id = "${DOC_WEWORK_CORPID}"
agent_id = "${DOC_WEWORK_AGENT_ID}"
secret = "${DOC_WEWORK_SECRET}"
```

Beego/ini 对子 section 的读法与现网 `secString("dingtalk", ...)` 同类：落实时用 `oauth.dingtalk` 段名；若 ini 库不支持点号段，改用 `[oauth_dingtalk]`，**example 与 `config.go` 必须一致**，在 F0 用 example 实测一次。

环境变量只 `DOC_*`。删除 `DOC_DINGTALK_READER`。

## 安全

| 项 | 要求 |
|----|------|
| state | ≥128 bit 随机、Session 绑定 provider、用过即删 |
| Redirect | `baseurl` 拼死路径；与 IdP 后台完全一致 |
| 日志 | 不打 code / token / secret；可打 provider + subject 指纹 |
| HTTPS | 生产回调必须 HTTPS |
| 禁用用户 | `members.status!=0` 拒绝写 Session |
| T11 CSP | 本期只在 06 列钉钉/企微脚本白名单，不改安全头 |

## 与原 T16 草稿差异

| 原 T16 | 本期 |
|--------|------|
| `Exchange(code string)` | `Complete(Callback)` |
| 对齐 tmp_reader | 删除 |
| 旧路由 301 | 删除旧路由 |
| `[dingtalk]` 迁移期兼容 | 硬切 |
| 包路径 `auth/oauth` | `auth/federated` |
| 包装 `thirdparty/dingtalk` | **删除该包**，调用内聚进 `federated/dingtalk.go` |
