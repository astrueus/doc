# 提交、合入并推送

用户说「提交并合并推送」、或执行本命令时，按本仓库 Git 约定一次做完。权威细则：[AGENTS.md](../../AGENTS.md)「功能分支保留」、[docs/release/git-workflow.md](../../docs/release/git-workflow.md) §8。

## 步骤

1. 看 `git status` / `diff` / `log`。没有改动则不要空提交。
2. 当前在 `master` 且有未提交改动：先 `git checkout -b` 合适前缀分支（`docs/` / `feat/` / `fix/` / `chore/` 等），再提交。不要直接在 `master` 上 commit。
3. 提交说明用简体中文：`<类型>(<范围>): <为什么>`。
4. `git checkout master`，`git merge --no-ff <功能分支>`，说明用 `merge(<分支名>): 合入…`。
5. `git push -u origin <功能分支>`，再 `git push origin master`。
6. **不要删除**刚合入的功能分支（本地、远程都留）。已合入仍留着的功能分支将超过约 3 条时：列出最旧一条，AskQuestion 确认后再删。

未获本命令或用户明确说合入 / 推送时，不要自行 commit / merge / push。
